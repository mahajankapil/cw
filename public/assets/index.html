Public Assets — Brand Logos

Add brand logo files to /public/assets/brands/ and list each filename in /public/assets/brands/brands.json. The page below renders the logos from that manifest.

How to add a logo
  • Copy your image into public/assets/brands/.
  • Edit public/assets/brands/brands.json and add the filename (e.g. "logo.png") to the array.
  • Refresh this page to see the new logo.

Supported formats: PNG, JPG, SVG, WebP.

Viewer serves static files from /public. URL: /assets/
